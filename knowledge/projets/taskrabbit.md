# Taskrabbit — Senior Mobile Engineer

## Project Overview

Tito Agudelo worked as a Senior Mobile Engineer at Taskrabbit in 2020, contributing to a React Native mobile application used by a large customer base.

The engagement focused on mobile application development, improving code maintainability, and supporting the evolution of an established production codebase.

One of the most important technical areas was the migration from JavaScript to TypeScript. This work involved improving type safety and making the codebase easier to understand, maintain, and extend while continuing to support ongoing product development.

The project provided experience working on a mature mobile application where code quality, testing, reliability, and collaboration were important to delivering changes safely.

## JavaScript-to-TypeScript Migration

One of the key technical aspects of the engagement was migrating JavaScript code toward TypeScript.

The purpose of this migration was to improve maintainability, introduce stronger typing, and make application behavior easier to reason about as the codebase evolved.

The work involved contributing to the transition while continuing to support normal product development.

### Why the Migration Mattered

TypeScript can help identify certain classes of errors during development, improve editor assistance, clarify data structures, and make refactoring safer.

In an established mobile application, these benefits are particularly valuable because changes can affect multiple components, application flows, and API integrations.

Tito's experience with this migration demonstrates his ability to work with an existing codebase, introduce improvements incrementally, and balance modernization with ongoing development needs.

## Automated Testing and Code Quality

- **Detox:** Used for end-to-end testing of React Native mobile application flows.

Automated testing helps developers detect regressions and gain confidence when changing an existing application, particularly during codebase migrations and ongoing feature development.
