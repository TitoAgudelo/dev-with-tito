### What made Trading Tower interesting?

Trading Tower was a challenging project because it combined several technical areas rather than focusing only on conventional frontend development. I worked with React, TypeScript, Ant Design, OpenAPI code generation, Go-based APIs, charts, and machine learning-related functionality. ### What was your frontend technology stack?

I worked primarily with React and TypeScript, using Ant Design for the user interface. I also worked with charts and data visualization, and used OpenAPI code generation as part of the API integration workflow.

### How did OpenAPI code generation help?

OpenAPI provides a contract describing API endpoints and their request and response structures. Generating code from that contract helps keep frontend integrations consistent with the API definitions and reduces the need to manually maintain duplicate types. It also improves the developer experience when working with TypeScript.

### What did you learn from the project?

The project reinforced the importance of combining strong frontend architecture with reliable API contracts and clear data presentation. It also provided experience working in a technically demanding environment where frontend functionality depended on several different parts of the system.
